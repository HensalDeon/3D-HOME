# Interior material sources

The oak diffuse and roughness maps are **Oak Veneer 01** by Jenelle van Heerden, downloaded from [Poly Haven](https://polyhaven.com/a/oak_veneer_01), released under [CC0](https://polyhaven.com/license). The manifest records original URLs and verified hashes. Maps are retained locally so rendering does not require a network connection.

The renderer applies the photographed veneer to the approved joinery using UV coordinates. Roughness and microscopic bump affect shading only; no displacement or geometry modifiers are used. Stone, plaster and fabric use procedural surface shaders.
