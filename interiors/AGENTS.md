# Interior image work

Before creating or revising interior presentation images, read [STYLE_REFERENCE.md](STYLE_REFERENCE.md) and inspect the original `images/06-kitchen-wide.png` and `images/06-kitchen-detail.png`. Use [STYLE_REFERENCE.html](STYLE_REFERENCE.html) for the full visual reference board.

- The user wants the original house palette and photographic realism to stay consistent across all rooms: muted natural oak, creamy ivory, pale sandy stone, fine material texture, soft daylight and restrained warm practical lighting.
- The current approved model and camera references govern layout. Historical style images do not authorize copying superseded architecture. Preserve stair routes, landings, headers, openings, fixtures, cabinet/shelf profiles and circulation.
- Use the original photographs as explicit style inputs for image generation. For multiple views of a room, also use a successful finished view as a consistency reference.
- Compare candidates against both the geometry reference and original kitchen images before replacing canonical PNGs. Plain model renders are geometry references and must not silently replace finished presentations.
- Save the exact prompts, source roles/hashes, geometry reference and final hashes. Update the image register, release metadata and consuming review pages together.
- Distinguish assistant visual review from user approval. Generated presentations are not pixel-exact measured drawings.
- Keep unrelated room images and model/drawing files unchanged unless the user includes them in the task.
